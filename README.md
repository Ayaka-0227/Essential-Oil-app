# Essential-Oil-app

## サービス概要
現状の精神状態・身体状況に合わせたアロマオイルの種類を提案をしてくれるアプリです。
利用者にメンタルチェックを行っていただくことで、上記の状態を把握し、チャート化にして教えてくれます。
その後、アプリが利用者にお勧めのアロマオイルを提案し、効果の説明をしてくれます。

<br><br>

## このサービスへの思い・作りたい理由
私は以前、アロマオイルを用いた整体で勤めていました。
そこではアロマオイルが数100種類あるのにも関わらず、主に使用されていたアロマオイルは20種類ほどだけでした。
こんなにも多くのアロマオイルをコレクションされているのに、使用されていないアロマオイルは数多くあり、勿体無いと感じました。
そんな時にメンタルチェックをして、偏りのないようお客様に適切なものを提供できたら無駄になるアロマオイルもなくなるのではないかと思い、このようなサービスを作ろうと考えました。

<br><br>

## ユーザー層について
主に30代～50代です。
20代は比較的、社会的ストレスが少なく、アロマオイルに触れ合う機会は少ないと考えました。
30代～50代はライフスタイルや職場での立場などで大きな変化があり、ストレスを抱えている方が多く、アロマオイルを身近に使用している方が多いと感じたからです。

<br><br>

## サービスの利用イメージ
適切なアロマオイルを使用することでストレスの解消、リラックス効果が生まれると思います。

<br><br>

## ユーザーの獲得について
ユーザー登録を行っていただき、ユーザーごとに異なるサービスを提供します。
メンタルチェックした結果は五角形レーダーチャートで表示され、どのような状態か教えてくれます。

<br><br>

## サービスの差別化ポイント・推しポイント<br>
他社サービスでは、利用目的ごとに8～20種類のアロマオイルを提示し、利用者が選択したオイルの詳細説明を表示する仕組みとなっています。しかし、提示されたアロマオイルの中から自分に合うものを選ぶのが難しいといったデメリットがあります。
本アプリではメンタルチェックを行うことで、これらのデメリットを解消し、アロマオイルを手軽に楽しんでいただけます。また利用者の状態に応じてアロマオイルをお勧めするため、効果を実感しやすい設計になっています。

<br><br>

## 機能候補<br>
- メンタルチェックシート:メンタルチェックと表示されたボタンの下に「このチェックは医療的な診断を行うものではありません」と注意書きをします。ボタンを押していただくことチェックシートへ移り、質問が提示されます。回答の平均時間は3分であり、すべて回答を終えることで結果が表示されます。質問は合計8問、回答は各5段階(0～4点まで)、過去7日間を基準にします。<br>

質問内容<br>
Q1: 緊張<br>
最近、肩や首に力が入りやすいと感じますか？<br>

Q2: 疲労<br>
何もしていなくても、疲れを感じることがありますか？<br>

Q3: 緊張<br>
呼吸が浅いと感じることがありますか？<br>

Q4: 不安<br>
気持ちが落ち着かず、そわそわすることがありますか？<br>

Q5: 睡眠<br>
夜、寝つくまでに時間がかかることがありますか？<br>

Q6: 疲労・睡眠<br>
朝起きたとき、疲れが残っていると感じますか？<br>

Q7: 不安<br>
最近、気分が沈みやすいと感じますか？<br>

Q8: 活力<br>
ゆっくりリラックスできる時間が取れていますか？<br>

- 五角形レーダーチャート:「ストレス(緊張)、疲労、不安、睡眠不足、活力不足」の項目で表示されます。<br>
1.全体像<br>
質問回答→回答を数値化→質問を5軸に割り当てる→軸ごとに平均を出す→0～100に正規化→レーダーチャートに反映<br>

2.軸ごとのスコア 算出方法<br>
以下は各質問ごとの点数を代入します。<br>
緊張 (Q1+Q3)/2<br>
疲労 (Q2+Q6)/2<br>
不安 (Q4+Q7)/2<br>
睡眠 (Q5+Q6)/2<br>
活力 4-Q8<br>

3.0～100に正規化<br>
0～4→0～100へ変換することでレーダーチャートが見やすくなります。<br>
100÷4=25<br>
軸スコア×25<br>
各5つの項目を正規化し、そのままレーダーチャートへ反映させます。<br>

4.レーダーチャートの読み取りルール<br>
一番数値が高い軸は最優先で整えたいポイントです。<br>
0～39= 感じにくい<br>
40～69= 感じやすい<br>
70～100= とても感じやすい<br>

5.アロマオイル決定ロジック<br>
5軸の中で最大値の軸を1つ選び、その軸に対応するアロマオイルを提案します。<br>
同点の場合は「緊張＞睡眠＞疲労＞不安＞活力」の優先順位となります。<br>
