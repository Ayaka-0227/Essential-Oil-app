# Essential-Oil-app

## サービス概要
現状の精神状態・身体状況に合わせたアロマオイルの種類を提案をしてくれるアプリです。
利用者にメンタルチェックを行っていただくことで、上記の状態を把握し、チャート化にして教えてくれます。
その後、アプリが利用者にお勧めのアロマオイルを提案し、効果の説明をしてくれます。

<br><br>

## このサービスへの思い・作りたい理由
私は以前、アロマオイルを用いた整体で勤めていました。
そこではアロマオイルが数100種類あるのにも関わらず、主に使用されていたアロマオイルは20種類ほどだけでした。
こんなにも多くのアロマオイルをコレクションされているのに、使用されていないアロマオイルは数多くあり、勿体無いと感じました。
そんな時にメンタルチェックをして、偏りのないようお客様に適切なものを提供できたら無駄になるアロマオイルもなくなるのではないかと思い、このようなサービスを作ろうと考えました。

<br><br>

## ユーザー層について
主に30代～50代です。
20代は比較的、社会的ストレスが少なく、アロマオイルに触れ合う機会は少ないと考えました。
30代～50代はライフスタイルや職場での立場などで大きな変化があり、ストレスを抱えている方が多く、アロマオイルを身近に使用している方が多いと感じたからです。

<br><br>

## サービスの利用イメージ
アロマオイルを用いた整体に来院されたお客様が、施術前に本サービスを利用します。
精神状態を可視化し、適したアロマオイルを提案することで、安心して施術を受けていただけるようにします。
また、アロマオイルを偏りなく使用できるため、在庫の無駄を減らすことにもつながります。

<br><br>

## ユーザーの獲得について
ユーザー登録を行っていただき、ユーザーごとに異なるサービスを提供します。
メンタルチェックした結果は八角形レーダーチャートで表示され、どのような状態か教えてくれます。
その後、香りの好みを選択していただくことでおすすめのアロマオイルを表示してくれます。

<br><br>

## サービスの差別化ポイント・推しポイント
他社サービスでは、利用目的ごとに8～20種類のアロマオイルを提示し、利用者が選択したオイルの詳細説明を表示する仕組みとなっています。しかし、提示されたアロマオイルの中から自分に合うものを選ぶのが難しいといったデメリットがあります。
本アプリではメンタルチェックを行うことで、これらのデメリットを解消し、アロマオイルを手軽に楽しんでいただけます。また利用者の状態に応じてアロマオイルをお勧めするため、効果を実感しやすい設計になっています。

<br><br>

## 機能候補
- メンタルチェックシート:メンタルチェックと表示されたボタンの下に「このチェックは医療的な診断を行うものではありません」と注意書きをします。ボタンを押していただくことチェックシートへ移り、質問が提示されます。回答の平均時間は3~4分であり、1画面1問で表示され、操作はタップのみで、戻ることも可能です (回答保持) 。すべて回答を終えることでおすすめのアプリオイルを1つ提案してくれます。質問は合計16問、回答は各5段階 ( 0～4点まで ) 、過去7日間を基準にします。

質問内容  
Q1 ストレス・緊張  
ふとした時に、肩やあごに力が入っていることはありますか？  

Q2 ストレス・緊張  
呼吸が浅いと感じることがありますか？  

Q3 疲労  
何もしていなくても、疲れを感じることがありますか？  

Q4 疲労  
しっかり休んでも、体が重たいと感じることはありますか？  

Q5 不安  
気持ちが落ち着かず、そわそわすることがありますか？  

Q6 不安  
先のことを考えると少し落ち着かない気持ちになることはありますか？  

Q7 睡眠不足  
夜、寝つくまでに時間がかかることがありますか？  

Q8 睡眠不足  
夜中や早朝に目が覚めることはありますか？  

Q9 感情の解放・安定  
気持ちを切り替えるのに時間がかかることはありますか？  

Q10 感情の解放・安定  
思っていることを、つい心の中に溜めてしまうことはありますか？  

Q11 活力・モチベーションの低下  
何かを始める前に少し腰が重いと感じることはありますか？  

Q12 活力・モチベーションの低下  
以前よりもやる気が出にくいと感じることはありますか？  

Q13 気分の落ち込み  
楽しいはずのことでも気持ちが動きにくいことはありますか？  

Q14 気分の落ち込み  
気分が沈む時間が少し増えたと感じることはありますか？  

Q15 集中力の低下  
目の前のことに集中しづらいと感じることはありますか？  

Q16 集中力の低下  
頭がぼーっとする時間が増えたと感じることはありますか？  

- 八角形レーダーチャート:「ストレス・緊張、不安、疲労、睡眠不足、活力・モチベーションの低下、気分の落ち込み、集中力の低下、感情の解放・安定」の項目で表示されます。  
1.全体像  
質問回答 → 8カテゴリーのスコア算出 → レーダーチャート表示 → 2～3つの上位カテゴリー抽出 → 対応アロマオイル候補を生成 → 香りのタイプ好みで絞り込む → 最終1本決定し + 説明  

2.軸ごとのスコア 算出方法  
回答の点数  
当てはまらない    0点  
あまりない        1点  
どちらともいえない 2点  
少しある          3点  
よくある          4点  

3.0～100に正規化  
0～4 → 0～100 へ変換することでレーダーチャートが見やすくなります。  
1カテゴリの最大点：2問 × 4点 = 8点  
正規化：カテゴリスコア = ( 取得点 ÷ 8 ) × 100  
各8つの項目を正規化し、そのままレーダーチャートへ反映させます。  

4.レーダーチャートの読み取りルール  
一番数値が高い軸は最優先で整えたいポイントです。  
| スコア範囲 | 状態 | 判定 |
|------------|------|------|
| 0～24 | ほぼ出ていない | 状態が安定 |
| 25～49 | やや出ている | 軽度 |
| 50～74 | 出ている | 要ケア |
| 75～100 | 強く出ている | 最優先 |

5.アロマオイル決定ロジック  
同点の場合は「不安＞緊張＞睡眠＞疲労＞気分＞感情＞集中＞活力」の優先順位となります。
